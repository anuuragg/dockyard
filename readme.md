# dockyard

A small, self-hosted PaaS for deploying Dockerized applications on your own machine.

The goal is to build a simple alternative to platforms like Heroku or Vercel, mainly for learning and experimentation.

## Status

🚧 **Work in progress**

Currently working on the core deployment flow:

* Deploy applications using a CLI
* Build and run Docker containers
* Assign ports automatically
* Store deployment information
* Route applications through Caddy
* Access apps using subdomains

More features will be added as the project develops.
